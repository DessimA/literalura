# literalura

Aplicacao backend em Java 25 com Spring Boot 3.4.13 que funciona como catalogo de livros interativo via console. Consome a API publica Gutendex (Projeto Gutenberg) e persiste dados em PostgreSQL 16 via Spring Data JPA. Implementa algoritmo de busca inteligente com regex e barreiras de palavra. Ambiente completo containerizado com Docker Compose e suite de testes com JUnit 5 e Mockito.

**Stack:** Java 25, Spring Boot 3.4, PostgreSQL 16, Docker Compose, JUnit 5
